# Category View Documentation

## Overview

The Category View is one of the main views of EasyTrack. It displays the user's expenses grouped according to their categories. This helps users understand how their money is distributed across different expense categories.

## Category Expense Calculations

The Category View uses the expense information provided by the Expense Model. It groups expenses based on their categories and calculates the total amount spent in each category.

It also calculates the percentage of expenses for each category based on the total expenses.
