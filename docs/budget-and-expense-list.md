
# Budget View and Expense List Documentation

## Overview

The Budget View and Expense List are important parts of EasyTrack.

The Budget View allows users to manage their available budget, while the Expense List displays the recorded expenses and provides tools for organizing expense information.


## Budget View Features

The Budget View provides users with tools to manage their personal budget.

Its features include:
- Displaying the current budget.
- Entering a custom budget amount.
- Adjusting the budget using the available controls.
- Clearing the current budget.
- Updating budget information after saving changes.


## Expense List Features

The Expense List displays the expenses recorded by the user.

Its features include:
- Displaying recorded expenses.
- Searching for expenses by name.
- Filtering expenses according to category.
- Editing existing expense records.
- Deleting expense records.

These features help users organize and manage their expense information.
