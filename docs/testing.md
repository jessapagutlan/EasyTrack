# EasyTrack – Application Testing

This document describes the tests performed to check the functionality of EasyTrack.

| Test Case | Expected Result |
|---|---|
| Add an expense with valid information | Expense is added successfully. |
| Submit an empty expense form | Validation error is displayed. |
| Edit an existing expense | Expense information is updated. |
| Delete an expense | Selected expense is removed. |
| Search for an expense | Matching expenses are displayed. |
| Filter expenses by category | Expenses from the selected category are displayed. |
| Set a budget | Budget amount is saved and displayed. |
| Refresh the browser | Previously saved data remains available. |

## Testing Notes

The application was tested to check its main features, form validation, data updates, and LocalStorage persistence.

Actual test results should be recorded after performing each test.
