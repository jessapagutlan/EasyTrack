
# Summary View Documentation

## Overview

The Summary View is a part of EasyTrack that provides users with an overview of their financial information. It helps users monitor their expenses and budget through a simple dashboard.


## Summary Calculations

The Summary View retrieves financial information from the Expense Model.

It uses the model's functions to obtain:
- Total expenses.
- Current budget.
- Remaining budget.

These values help users understand their current financial situation.


## Summary View Features

- Displays the total amount of expenses.
- Shows the available budget.
- Displays the remaining balance.
- Updates the displayed information when expense or budget data changes.
- Formats monetary values for easier reading.
