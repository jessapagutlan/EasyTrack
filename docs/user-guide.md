# EasyTrack – User Guide

## 1. Adding an Expense

1. Open the EasyTrack application.
2. Navigate to the expense form.
3. Enter the required expense information.
4. Submit the form.
5. Check whether the expense appears in the expense list.

## 2. Editing an Expense

1. Find the expense you want to update.
2. Select its edit option.
3. Modify the necessary information.
4. Save your changes.

## 3. Deleting an Expense

1. Find the expense you want to remove.
2. Select its delete option.
3. Check that the expense is removed from the list.

## 4. Viewing Expense Summaries

Open the summary section to view the total expenses, transaction count, and average expense.

## 5. Managing Your Budget

1. Navigate to the budget section.
2. Enter or select your desired budget amount.
3. Check your remaining balance.
4. Use the clear budget option when you want to remove the budget.

## 6. Searching and Filtering

Use the available search and filter controls to find specific expense records.
