# EasyTrack
A Simple Personal Expense Tracker

## Features

- Add new expenses.
- Edit existing expenses.
- Delete expense records.
- View total expenses and transaction summaries.
- View expenses by category.
- Search and filter expense records.
- Set a budget and monitor the remaining balance.
- Save data using browser LocalStorage.

## Technologies Used

- HTML
- CSS
- JavaScript
- JavaScript ES Modules
- LocalStorage

## How to Run the Application

1. Download or clone the EasyTrack repository.
2. Open the project folder in Visual Studio Code.
3. Run the application using a local development server, such as Live Server.
4. Open the application in your browser.

## Project Architecture

EasyTrack follows the Model-View-Controller (MVC) architectural pattern.

- Model: Manages the application's data and business logic.
- View: Handles the presentation and user interface.
- Controller: Connects user interactions with the Model and Views.
